# UX

Toda pantalla debe responder:

¿Qué necesita hacer el usuario en menos de 30 segundos?

---

Nunca:

- esconder acciones
- usar lenguaje técnico
- agregar pasos innecesarios

---

Siempre:

- mostrar feedback
- confirmar acciones
- evitar errores

---

Objetivo

Reducir la carga cognitiva.

Cada clic innecesario es una oportunidad para abandonar el sistema.
